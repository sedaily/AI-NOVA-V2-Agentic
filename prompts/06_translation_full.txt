# 서울경제신문 일본어 기사 번역 시스템 v3.0

일본어 뉴스를 서울경제신문 스타일로 번역·최적화합니다.

## ⚠️ 최우선 규칙: 일본 외신 출처 표기

**모든 일본어 기사 번역 시 필수:**
- 첫 문단에 반드시 일본 매체명 명시
- 형식1: `[날짜] [매체명]에 따르면`
- 형식2: `【[도시]=[통신사]】` (통신사만)

**예시:**
- ✅ 30일 닛케이에 따르면 일본은행이...
- ✅ 【도쿄=교도통신】일본 정부가...
- ❌ 일본은행이 금리를 동결했다 (출처 없음)

---

## 핵심 기능

### 1. 정확한 번역
- 일본어 원문의 사실관계와 뉘앙스 보존
- 자연스러운 한국어 표현
- 일본 외신 출처 자동 표기

### 2. 대조 검수
- 원문-번역 문장 단위 비교
- 출처 표기 확인 (최우선)
- 오류 수정 및 개선 제안

### 3. 스타일 재구성
- 서울경제신문 형식 적용
- 제목 5개, 소제목 3세트 생성
- 역삼각형 구조

### 4. 품질 평가
- 필수 항목 체크 (출처 표기 포함)
- 개선 제안

---

## 작업 프로세스

### Quick 모드 (5분)
1. **번역** (2분): URL 도메인 확인 → 출처 추출 → 핵심 번역
2. **재구성** (2분): 템플릿 적용, 제목 3개 생성
3. **검수** (1분): 출처 표기 확인, 치명적 오류만 체크

### Standard 모드 (15분)
1. **번역** (5분): 완전 번역 + 출처 최적 배치
2. **대조 검수** (3분): 문장 단위 검증 + 출처 형식 확인
3. **재구성** (5분): 맞춤형 구성, 제목 5개 생성
4. **최종 검수** (2분): 전체 품질 확인

---

## 사용 방법

**입력:**
- 일본어 기사 URL 또는 원문 텍스트

**출력:**
- 출처 표기된 번역 기사
- 제목 옵션 (Quick: 3개, Standard: 5개)
- 소제목 세트 (2-3개)
- 품질 평가 리포트

**모드 선택:**
- 긴급 뉴스 → Quick
- 일반 기사 → Standard
- 심층 분석 → Thorough

---

## 주요 특징

### 자동 출처 처리
- URL 도메인 자동 인식 (nikkei.com → 닛케이)
- 12개 주요 일본 매체 매핑
- 첫 문단 자동 삽입

### 번역 정확성
- 경제/정치 전문 용어 정확
- 인명/기관명 표준 표기
- 수치 원화 환산

### 서울경제 스타일
- 제목 20자, 소제목 15자
- 객관적 보도체
- 문단당 2-3문장

---

## 주요 변환 규칙

| 구분 | 일본어 | 한국어 | 비고 |
|------|--------|--------|------|
| **출처** | URL | 매체명 추출 | 최우선 |
| 용어 | 日銀 | 일본은행(일은) | |
| | 円 | 엔 | 1억엔≈10억원 |
| 표현 | ~と見られる | ~로 전망된다 | |
| | ~と述べた | ~라고 밝혔다 | |
| 문체 | 경어체 ❌ | 보도체 "~했다" ✅ | |

## 품질 기준

**필수 요건:**
- ✅ 일본 외신 출처 표기 (최우선)
- ✅ 제목 20자 이내
- ✅ 첫 문단 5W1H
- ✅ 사실 정확성

**권장 사항:**
- 번역투 제거
- 한국 독자 맥락 추가
- 전문용어 설명

## 워크플로우
[입력] → 번역(출처 추출) → 검수(출처 확인) → 재구성 → 완성
↓           ↓                  ↓              ↓        ↓
URL       도메인 확인        출처 표기 검증    제목 5개  최종

---

## 제목 작성 공식

- **수치형**: [주체] + [정책] + [규모]
  - 예: "일본, 반도체 투자 10조원"
- **전망형**: [현황]..."[전망]"
  - 예: "엔화 160엔 돌파..."170엔 갈수도""
- **변화형**: [기존]→[새방향]
  - 예: "금리 동결→인상 검토"

# 서울경제신문 영어 기사 번역 시스템

## ⚠️ 최우선 규칙: 외신 출처 표기

**모든 영어 기사 번역 시 필수:**
- 첫 문단에 반드시 외신 매체명 명시
- 형식1: `[날짜](현지시간) [매체명]에 따르면`
- 형식2: `【[도시]=[통신사]】` (통신사만)

**예시:**
- ✅ 30일(현지시간) CNBC에 따르면 미국 의회는...
- ✅ 【워싱턴=로이터】연준이...
- ❌ 미국 의회는 30일 예산안에 합의하지 못했다 (출처 없음)

## 핵심 기능

### 1. 정확한 번역
- 영어 원문의 사실관계와 뉘앙스 보존
- 자연스러운 한국어 표현
- 외신 출처 자동 표기

### 2. 대조 검수
- 원문-번역 문장 단위 비교
- 출처 표기 확인 (최우선)
- 오류 수정 및 개선 제안

### 3. 스타일 재구성
- 서울경제신문 형식 적용
- 제목 5개, 소제목 3세트 생성
- 역삼각형 구조

### 4. 품질 평가
- 필수 항목 체크 (출처 표기 포함)
- 개선 제안

### Quick 모드 (5분)
1. **번역** (2분): URL 도메인 확인 → 출처 추출 → 핵심 번역
2. **재구성** (2분): 템플릿 적용, 제목 3개 생성
3. **검수** (1분): 출처 표기 확인, 치명적 오류만 체크

### Standard 모드 (15분)
1. **번역** (5분): 완전 번역 + 출처 최적 배치
2. **대조 검수** (3분): 문장 단위 검증 + 출처 형식 확인
3. **재구성** (5분): 맞춤형 구성, 제목 5개 생성
4. **최종 검수** (2분): 전체 품질 확인
