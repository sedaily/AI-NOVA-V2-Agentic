# Knowledge Base - 서울경제신문 종합 스타일북

```markdown
# 서울경제신문 종합 스타일 가이드
*최종 업데이트: 2025년 10월*

## 1. 서울경제신문 정체성과 철학

### 1.1 기본 정보
- **창간**: 1960년 8월 1일 (대한민국 최초의 경제신문)
- **사명**: "시시비비에 철두철미할 것"
- **비전**: "국민 개개인의 성공과 성취, 그리고 경제생활의 풍요와 여유"
- **슬로건**: "대한민국 경제의 발전과 국민 개개인의 경제적 성공에 기여"

### 1.2 핵심 독자층
- **주요 타깃**: 30-60대 비즈니스 리더, 투자자, 정책 관계자
- **오피니언 리더**: 경제 의사결정권자, 중소기업 경영진, 정책 실무자
- **특수 타깃**: 상황에 따라 10-20대, Z세대, 외국인 독자 고려
- **독자 관심사**: ROI, 시장 기회, 정책 영향, 투자, 재테크, 취업, 창업

### 1.3 서울경제 차별화 지점
- 경제 전문성 + 대중적 가독성
- 데이터 정확성 + 스토리텔링
- 글로벌 시각 + 한국 맥락
- 심층 분석 + 실용적 정보
- 중소기업/스타트업 친화적
- 정책 분석 강점
- 산업 현장 밀착

### 1.4 저널리즘 10대 원칙
1. **경제 전문성**: 복잡한 경제 개념을 명확하고 간결하게 설명
2. **객관성과 중립성**: 사실 기반, 균형 잡힌 시각, 불필요한 찬사나 비난 배제
3. **심층 분석**: 단순 사실 전달 넘어 원인, 영향, 전망 분석
4. **데이터 기반**: 경제 지표, 통계, 차트 활용으로 신뢰성 제고
5. **글로벌 시각**: 국내외 경제 동향을 함께 고려한 폭넓은 관점
6. **실용적 정보**: 독자의 투자, 재테크, 취업, 창업에 도움
7. **혁신적 접근**: 4차 산업혁명, 디지털 전환, 친환경 경제 등 미래 트렌드
8. **윤리적 저널리즘**: 정확성, 공정성, 독립성 준수
9. **독자 중심 소통**: 전문 용어 설명, 독자 눈높이 고려
10. **AI 활용**: 데이터 분석, 트렌드 예측으로 통찰력 있는 정보 제공

## 2. 서울경제 고유 표기법 (절대 준수)

### 2.1 필수 용어 사용
- **시간 표현**
  - '지난해' 사용 (❌작년)
  - '올해' 사용 (❌금년)
  - '어제' (❌작일)
  - '내일' (❌명일)
  
- **퍼센트 표기**
  - '%포인트' 사용 (❌%P, %p)
  - 예: "금리 2%포인트 인상"

- **수량 표기**
  - '200여 개' (❌200여개) - 띄어쓰기 필수
  - '8700여 명' (❌8700여명)
  - '만 19세' (❌만19세) - 띄어쓰기

### 2.2 접속사와 문장 연결
- '한편 정부는' (❌한편, 정부는) - 쉼표 없음
- 축약형 금지: '향해서는' (❌향해선)
- '~해서는' (❌~해선)

### 2.3 특수 기호 사용
- **관련 기사**: ★관련 기사 5면
- **추가 안내**: ※다음은 인터뷰 전문
- 겹따옴표: 직접 인용
- 홑따옴표: 특별한 용어나 강조

## 3. 표기 규정

### 3.1 숫자와 단위
- **기본**: 아라비아 숫자 사용
- **만 단위**: 띄어쓰기 - "1억 2000만 원"
- **소수**: 온점(.) 사용 - "3.14"
- **퍼센트**: "3.5%"
- **달러 환산**: "100억달러(약 13조원)"
- **증감률**: 소수점 첫째 자리까지 - "2.3% 증가"

### 3.2 인명과 직함
- **한국인**: 
  - 첫 언급: "손태승 전 우리금융 회장"
  - 재언급: "손 전 회장"
- **외국인**:
  - 첫 언급: "제롬 파월 연방준비제도(Fed·연준) 의장"
  - 재언급: "파월 의장"
- **중국인**: 한자 병기 - "시진핑(習近平) 중국 국가주석"

### 3.3 기관명과 약어
- **첫 언급**: 풀네임+약어 병기
  - "국제통화기금(IMF)"
  - "한국은행(한은)"
  - "연방준비제도(Fed·연준)"
- **정부 부처**: 서열 순 나열
- **외국 기관**: 국립국어원 표기법 준수

### 3.4 날짜와 시간
- **날짜**: "2025년 1월 6일"
- **시간**: "오전 10시 30분" (오전/오후 구분)
- **기간**: "2020~2025년" (뒤 연도도 4자리)
- **현지시간**: "30일(현지시간)"

### 3.5 외신 출처 표기 (최우선)
- **Option 1**: "30일(현지시간) CNBC에 따르면..."
- **Option 2**: "【워싱턴=로이터】"
- 반드시 첫 문단에 명시
- 주요 매체:
  - cnbc.com → CNBC
  - reuters.com → 로이터
  - bloomberg.com → 블룸버그
  - wsj.com → 월스트리트저널(WSJ)
  - ft.com → 파이낸셜타임스(FT)

## 4. 문장 작성 기법

### 4.1 기본 원칙
- **1기사 1주제**: 한 기사에서 한 가지 주제만
- **1문장 1정보**: 한 문장에 한 가지 사실만
- **평이성과 명료성**: 평이하면서도 명확한 정보 전달

### 4.2 문장 규격
- **일반 기사**: 50자 이내
- **숏츠용**: 40자 이내
- **주어-술어 거리**: 10자 이내
- **단락**: 2-3문장 구성

### 4.3 문체 원칙
- **능동태 우선**: 수동태는 20% 이내
- **평어체 기본**: 별도 지시 없으면 평어체
- **종결어미 축약**: 
  - '하였습니다' → '했습니다'
  - '어떠했나요' → '어땠나요'
  - '되었습니다' → '됐습니다'

### 4.4 금지 표현
- **추측성**: "~인 셈이다", "~로 풀이된다", "~로 보인다"
- **모호함**: "~라는 지적이다", "~라는 분석이다"
- **번역투**: "~에 대한", "~으로부터", "~에 의해"
- **구어체 축약**: "향해선" (→향해서는), "위해선" (→위해서는)
- **과장된 수식어**: "충격적인", "놀라운", "폭발적인"
- **주관적 형용사**: 최소화

## 5. 기사 유형별 작성법

### 5.1 스트레이트 뉴스
- **구조**: 역피라미드 철저 준수
- **리드**: 5W1H 중 최소 4개, 30자 이내 핵심
- **본문**: 중요도 순 배치
- **인용**: 2-3개 제한
- **특징**: 팩트 중심, 객관적 서술

#### 예시 구조
```
[리드] 누가+무엇을+언제 = 핵심 사실
[2단락] 구체적 내용 (수치, 규모)
[3단락] 배경과 맥락
[4단락] 전문가 평가/인용
[5단락] 향후 전망
```

### 5.2 해설/분석 기사
- **구조**: 배경 → 현황 → 원인 → 영향 → 전망
- **특징**: 
  - 복수 전문가 견해 필수 (최소 2-3명)
  - 데이터 기반 분석
  - 찬반 균형 유지
- **목적**: 복잡한 이슈의 맥락 설명

### 5.3 피처/르포 기사
- **구조**: 장면 묘사 → 갈등 → 절정 → 해결
- **특징**:
  - 현장감 있는 묘사
  - 인물 중심 스토리
  - 디테일과 감정 포함
- **기법**: 내러티브 스토리텔링

### 5.4 인터뷰 기사
- **구조**: 핵심 발언 → 세부 내용 재구성
- **원칙**:
  - 질문은 짧게, 답변은 길게
  - 시간순이 아닌 중요도순 재배치
  - 인물 소개 충실
- **인용**: 5-6개까지 가능

### 5.5 칼럼/기자의 눈
- **구조**: 문제 제기 → 분석 → 주장 → 결론
- **특징**:
  - 기자 주관 개입 가능
  - 명확한 관점 제시
  - 논리적 전개
- **주의**: 균형감 유지

## 6. 기사 작성 프로세스

### 6.1 취재 준비
1. 사안의 중요도 판단 (영향성, 특이성, 시의성, 근접성, 저명성)
2. 취재원 선정 (복수 확보)
3. 데이터/자료 수집
4. 맥락과 배경 파악

### 6.2 작성 단계
1. **핵심 메시지 정리**
   - 한 문장으로 요약
   - 독자 관점에서 중요도 판단
   
2. **구조 설계**
   - 기사 유형 결정
   - 단락별 정보 배치
   - 인용과 데이터 위치 결정
   
3. **초고 작성**
   - 리드 작성 (가장 중요)
   - 본문 전개
   - 마무리
   
4. **퇴고**
   - 팩트 체크
   - 문장 다듬기
   - 서울경제 스타일 적용
   - 오탈자 확인

### 6.3 품질 체크리스트
- [ ] 5W1H 충족
- [ ] 팩트 정확성
- [ ] 출처 명시
- [ ] 숫자/단위 정확성
- [ ] 전문용어 설명
- [ ] 문장 길이 적절
- [ ] 능동태 사용
- [ ] 서울경제 표기법 준수

## 7. 제목 작성법

### 7.1 원칙
- **정확성**: 기사 내용 정확히 반영
- **간결성**: 12자 이내 원칙
- **흥미성**: 독자 관심 유발
- **구체성**: 모호한 표현 지양

### 7.2 구조
- 주제목 + 부제목
- 주요 키워드 포함
- 숫자/수치 활용
- 인용부호 적절 사용

### 7.3 유형별 예시
- **속보**: "금리 0.25%p 인상…연 5.5% 돌파"
- **분석**: "왜 청년은 주식 대신 금을 살까"
- **단독**: "[단독] 삼성, 美에 300억달러 투자"
- **인터뷰**: "이재용 '반도체가 미래다'"

## 8. 디지털 최적화

### 8.1 모바일 고려사항
- 단락 짧게 (2-3문장)
- 스크롤 단위 사고
- 시각적 분절 (소제목 활용)
- 중요 정보 전방 배치

### 8.2 SEO 최적화
- 키워드 자연스럽게 배치
- 제목과 첫 단락에 핵심 키워드
- 메타 설명 최적화
- 이미지 alt 텍스트

### 8.3 멀티미디어 활용
- 인포그래픽
- 차트와 그래프
- 동영상
- 인터랙티브 콘텐츠

## 9. 뉴스 가치 판단 기준

### 9.1 5대 뉴스 가치
1. **영향성**: 영향받는 독자 수
2. **특이성**: 최초, 최대, 유일
3. **시의성**: 발생 시점과 현재 간격
4. **근접성**: 물리적/심리적 거리
5. **저명성**: 인물/기관 인지도

### 9.2 추가 고려사항
- 독자 관심도
- 시대적 배경
- 지리적 조건
- 문화적 맥락

## 10. 윤리 규정

### 10.1 취재 윤리
- 출처 불분명 정보 사용 금지
- 취재원 보호
- 이해충돌 방지
- 정확성 우선

### 10.2 보도 윤리
- 공정성과 균형성
- 피해 최소화
- 사생활 존중
- 선정성 배제

### 10.3 정정과 반론
- 오류 발견 시 신속 정정
- 반론권 보장
- 투명한 수정 이력

## 11. 경제 전문 용어 가이드

### 11.2 용어 설명 원칙

## 12. 자주 하는 실수

### 12.1 표기 오류
- ❌ "작년" → ✅ "지난해"
- ❌ "3%P" → ✅ "3%포인트"
- ❌ "100여개" → ✅ "100여 개"
- ❌ "한편," → ✅ "한편"

### 12.2 문장 오류
- ❌ "~에 대한 우려" → ✅ "~ 우려"
- ❌ "~에 의해 발표됐다" → ✅ "~가 발표했다"
- ❌ "~인 것으로 나타났다" → ✅ "~로 나타났다"

### 12.3 구조 오류
- 리드에 부차적 정보
- 역피라미드 무시

- 출처 불명확

## 14. 영어 기사 번역 특별 지침

### 14.1 번역 원칙
- 의미 우선 (직역 < 의역)

# 진화하는 구조 인사이트

## 서울경제 롱폼 특징

### 경제지 완독률 비밀
- 첫 단락: 돈이 되는 정보
- 중간: 왜 중요한지 설명
- 마지막: 어떻게 활용할지

### 비즈니스 리더가 원하는 구조
1. 핵심 숫자와 영향 (바쁜 사람용)
2. 배경과 맥락 (이해하고 싶은 사람용)
3. 상세 분석 (깊이 알고 싶은 사람용)
4. 시사점과 전망 (의사결정용)

### 완주율의 진실
- 첫 단락 이탈: 30%
- 중간 이탈: 40%  
- 70% 지점 이탈: 20%
- 완주: 10%
*하지만 좋은 구조는 완주율 40%도 가능*

### 구조가 내용을 이긴다
- 같은 내용 + 다른 구조 = 2배 완주율
- A→B→C보다 C→A→B가 나을 때 많음
- 첫 단락과 마지막 단락이 전체를 결정

### 독자 심리의 변화
- 2020년: 정보 갈증 시대
- 2023년: 정보 과부하 시대  
- 2025년: 큐레이션 요구 시대
*더 많이보다 더 잘 정리된 것*

## 장르별 최적 구조 (계속 실험 중)

### 경제 분석 기사
- 최악: 이론 → 데이터 → 사례
- 최선: 충격 사례 → 이유 → 데이터 증명
- 완주율 차이: 15% vs 45%

### 정책 해설 기사
- 최악: 정책 설명 → 배경 → 영향
- 최선: "당신에게 미칠 영향" → 정책 → 이유
- 체감이 먼저, 설명은 나중

### 기업 심층 분석
- 최악: 역사 → 현재 → 미래
- 최선: 현재 위기 → 어떻게 여기까지 → 돌파구
- 드라마가 있어야 읽힌다

### 산업 트렌드
- 최악: 통계 나열
- 최선: 대표 사례 → 패턴 → 통계로 증명
- 구체 → 추상이 자연스럽다

# 서울경제신문 경제 용어 가이드
*경제 기사 작성 시 정확한 용어 사용과 독자 친화적 설명을 위한 실무 가이드*

## 1. 기업 실적/재무 용어

### 실적 관련
- **매출 (Revenue/Sales)**
  - 사용: 기업의 총 판매액
  - 예시: "삼성전자 3분기 매출 76조원"
  - 주의: 매출액, 매출 둘 다 가능

- **영업이익 (Operating Profit)**
  - 사용: 본업에서 벌어들인 이익
  - 예시: "영업이익 12조원, 영업이익률 15.8%"
  - 설명 필요: 일반 독자는 순이익과 혼동

- **순이익 (Net Profit)**
  - 사용: 모든 비용 제한 최종 이익
  - 예시: "당기순이익 10조원 달성"
  - 비교: 전년 동기 대비 필수

- **EBITDA**
  - 사용: 상각전영업이익
  - 첫 언급: "EBITDA(상각전영업이익)"
  - 설명: 현금 창출 능력 지표

### 수익성 지표
- **영업이익률**: 매출 대비 영업이익 비율
- **순이익률**: 매출 대비 순이익 비율
- **ROE**: 자기자본이익률 (첫 언급시 풀어쓰기)
- **ROA**: 총자산이익률 (첫 언급시 풀어쓰기)
- **마진**: 수익률 (문맥에 따라 영업마진, 순마진)

## 2. 주식/증권 용어

### 시장 동향
- **상승/하락 표현**
  - 급등: 5% 이상 상승
  - 급락/폭락: 5% 이상 하락
  - 강세/약세: 전반적 흐름
  - 보합: 변동 미미 (±1% 내외)

- **랠리 (Rally)**
  - 사용: 지속적 상승세
  - 예시: "3일 연속 상승 랠리"
  - 주의: 단기 상승에만 사용

- **조정 (Correction)**
  - 사용: 10% 내외 하락
  - 예시: "과열 후 기술적 조정"
  - 구분: 베어마켓(20% 이상)과 구별

### 투자 지표
- **PER (Price Earning Ratio)**
  - 첫 언급: "PER(주가수익비율)"
  - 설명: 낮을수록 저평가
  - 비교: 업종 평균과 비교 필수

- **PBR (Price Book Ratio)**
  - 첫 언급: "PBR(주가순자산비율)"
  - 기준: 1배 미만은 청산가치 이하

- **컨센서스 (Consensus)**
  - 사용: 증권사 평균 전망치
  - 예시: "컨센서스 상회/하회"
  - 표기: 시장 전망치로도 표현 가능

## 3. 경제 지표

### 성장 지표
- **GDP (Gross Domestic Product)**
  - 첫 언급: "GDP(국내총생산)"
  - 표현: 전년 대비, 전분기 대비 구분
  - 실질/명목 구분 필수

- **경제성장률**
  - 표기: "3.5% 성장" (연율 명시)
  - 비교: OECD 평균, 주요국 대비

### 물가 지표
- **CPI (Consumer Price Index)**
  - 첫 언급: "CPI(소비자물가지수)"
  - 표현: "전년 동월 대비 2.5% 상승"

- **인플레이션/디플레이션**
  - 인플레이션: 2% 이상 지속 상승
  - 디플레이션: 마이너스 물가
  - 디스인플레이션: 상승률 둔화

### 고용 지표
- **실업률**
  - 표기: "청년실업률 7.2%"
  - 구분: 체감실업률과 공식실업률

- **고용률**
  - 설명: 15-64세 인구 중 취업자 비율
  - 비교: OECD 평균 필수

## 4. 금융/통화 용어

### 금리 관련
- **기준금리**
  - 표기: "연 3.5%"
  - 변동: "0.25%포인트 인상" (❌%p)

- **금리 스프레드**
  - 설명: 금리 차이
  - 예시: "한미 금리차 1.5%포인트"

### 환율 관련
- **원/달러 환율**
  - 표기: "달러당 1,300원"
  - 변동: "10원 상승(원화 약세)"
  - 주의: 상승=원화 약세 명시

- **환율 변동성**
  - 고환율: 1,400원 이상
  - 저환율: 1,100원 이하

## 5. 부동산/건설 용어

### 시장 지표
- **매매가/전세가**
  - 표기: "아파트 매매가 3.5% 상승"
  - 기준: 전월 대비, 전년 대비 구분

- **전세가율**
  - 설명: 매매가 대비 전세가 비율
  - 기준: 70% 이상 높음

### 정책 용어
- **LTV (Loan To Value)**
  - 첫 언급: "LTV(주택담보대출비율)"
  - 예시: "LTV 40% 적용"

- **DTI/DSR**
  - DTI: 총부채상환비율
  - DSR: 총부채원리금상환비율
  - 차이점 설명 필요

## 6. 국제 경제 용어

### 국제기구
- **IMF**: 국제통화기금(IMF)
- **World Bank**: 세계은행(WB)
- **WTO**: 세계무역기구(WTO)
- **OECD**: 경제협력개발기구(OECD)
- **Fed**: 미국 연방준비제도(Fed·연준)
- **ECB**: 유럽중앙은행(ECB)
- **BOJ**: 일본은행(BOJ)

### 통상 용어
- **FTA**: 자유무역협정(FTA)
- **관세**: 수입품에 부과하는 세금
- **무역수지**: 수출-수입 차액
- **경상수지**: 상품+서비스+소득 수지

## 7. 신경제/기술 용어

### 디지털 경제
- **유니콘 기업**
  - 설명: 기업가치 10억달러 이상 스타트업
  - 예시: "유니콘 기업 선정"

- **빅테크**
  - 대상: 구글, 애플, 메타, 아마존 등
  - 국내: 네이버, 카카오

### ESG/지속가능성
- **ESG**
  - 첫 언급: "ESG(환경·사회·지배구조)"
  - 중요성: 투자 기준으로 부상

- **탄소중립**
  - 설명: 순 탄소배출 제로
  - 목표: "2050 탄소중립"

## 8. 용어 설명 원칙

### 첫 사용 원칙
1. 약어는 풀어쓰고 괄호에 약어
   - ✅ "국제통화기금(IMF)"
   - ❌ "IMF(국제통화기금)"

## 검증된 서사 구조들

### 영웅의 여정 (Hero's Journey)
- 평범한 세계 → 소명 → 거부 → 시련 → 보상
- 독자가 주인공과 함께 성장
- 기사 적용: 문제 → 도전 → 실패 → 극복 → 통찰

- 수수께끼 제시 → 단서 → 반전 → 해답

*탐사보도, 원인 분석에 최적*

### 대립 구조 (Conflict Structure)
- A vs B → 충돌 → 심화 → 해결 또는 공존
- 긴장감이 독자를 붙잡음
- 기사 적용: 찬반 → 각자 논리 → 충돌 지점 → 전망
*논쟁적 이슈에 효과적*

### 모자이크 구조 (Mosaic Structure)
- 조각 1 + 조각 2 + 조각 3 = 전체 그림
- 퍼즐 맞추는 재미
- 기사 적용: 사례들 → 패턴 발견 → 큰 그림
*트렌드 분석, 사회 현상에 적합*

### 순환 구조 (Circular Structure)
- 끝이 다시 시작과 연결
- "아, 그래서 처음에..."
- 기사 적용: 현재 → 과거 → 과정 → 다시 현재(새로운 이해)
*역사적 맥락, 장기 프로젝트에 유효*

# 서울경제신문 경제 용어 가이드
*경제 기사 작성 시 정확한 용어 사용과 독자 친화적 설명을 위한 실무 가이드*

## 1. 기업 실적/재무 용어

### 실적 관련
- **매출 (Revenue/Sales)**
  - 사용: 기업의 총 판매액
  - 예시: "삼성전자 3분기 매출 76조원"
  - 주의: 매출액, 매출 둘 다 가능

- **영업이익 (Operating Profit)**
  - 사용: 본업에서 벌어들인 이익
  - 예시: "영업이익 12조원, 영업이익률 15.8%"
  - 설명 필요: 일반 독자는 순이익과 혼동

- **순이익 (Net Profit)**
  - 사용: 모든 비용 제한 최종 이익
  - 예시: "당기순이익 10조원 달성"
  - 비교: 전년 동기 대비 필수

- **EBITDA**
  - 사용: 상각전영업이익
  - 첫 언급: "EBITDA(상각전영업이익)"
  - 설명: 현금 창출 능력 지표

### 수익성 지표
- **영업이익률**: 매출 대비 영업이익 비율
- **순이익률**: 매출 대비 순이익 비율
- **ROE**: 자기자본이익률 (첫 언급시 풀어쓰기)
- **ROA**: 총자산이익률 (첫 언급시 풀어쓰기)
- **마진**: 수익률 (문맥에 따라 영업마진, 순마진)

## 2. 주식/증권 용어

### 시장 동향
- **상승/하락 표현**
  - 급등: 5% 이상 상승
  - 급락/폭락: 5% 이상 하락
  - 강세/약세: 전반적 흐름
  - 보합: 변동 미미 (±1% 내외)

- **랠리 (Rally)**
  - 사용: 지속적 상승세
  - 예시: "3일 연속 상승 랠리"
  - 주의: 단기 상승에만 사용

- **조정 (Correction)**
  - 사용: 10% 내외 하락
  - 예시: "과열 후 기술적 조정"
  - 구분: 베어마켓(20% 이상)과 구별

### 투자 지표
- **PER (Price Earning Ratio)**
  - 첫 언급: "PER(주가수익비율)"
  - 설명: 낮을수록 저평가
  - 비교: 업종 평균과 비교 필수

- **PBR (Price Book Ratio)**
  - 첫 언급: "PBR(주가순자산비율)"
  - 기준: 1배 미만은 청산가치 이하

- **컨센서스 (Consensus)**
  - 사용: 증권사 평균 전망치
  - 예시: "컨센서스 상회/하회"
  - 표기: 시장 전망치로도 표현 가능

## 3. 경제 지표

### 성장 지표
- **GDP (Gross Domestic Product)**
  - 첫 언급: "GDP(국내총생산)"
  - 표현: 전년 대비, 전분기 대비 구분
  - 실질/명목 구분 필수

- **경제성장률**
  - 표기: "3.5% 성장" (연율 명시)
  - 비교: OECD 평균, 주요국 대비

### 물가 지표
- **CPI (Consumer Price Index)**
  - 첫 언급: "CPI(소비자물가지수)"
  - 표현: "전년 동월 대비 2.5% 상승"

- **인플레이션/디플레이션**
  - 인플레이션: 2% 이상 지속 상승
  - 디플레이션: 마이너스 물가
  - 디스인플레이션: 상승률 둔화

### 고용 지표
- **실업률**
  - 표기: "청년실업률 7.2%"
  - 구분: 체감실업률과 공식실업률

- **고용률**
  - 설명: 15-64세 인구 중 취업자 비율
  - 비교: OECD 평균 필수

## 4. 금융/통화 용어

### 금리 관련
- **기준금리**
  - 표기: "연 3.5%"
  - 변동: "0.25%포인트 인상" (❌%p)

- **금리 스프레드**
  - 설명: 금리 차이
  - 예시: "한미 금리차 1.5%포인트"

### 환율 관련
- **원/달러 환율**
  - 표기: "달러당 1,300원"
  - 변동: "10원 상승(원화 약세)"
  - 주의: 상승=원화 약세 명시

- **환율 변동성**
  - 고환율: 1,400원 이상
  - 저환율: 1,100원 이하

## 5. 부동산/건설 용어

### 시장 지표
- **매매가/전세가**
  - 표기: "아파트 매매가 3.5% 상승"
  - 기준: 전월 대비, 전년 대비 구분

- **전세가율**
  - 설명: 매매가 대비 전세가 비율
  - 기준: 70% 이상 높음

### 정책 용어
- **LTV (Loan To Value)**
  - 첫 언급: "LTV(주택담보대출비율)"
  - 예시: "LTV 40% 적용"

- **DTI/DSR**
  - DTI: 총부채상환비율

  - 설명 필요: 일반 독자는 순이익과 혼동

- **순이익 (Net Profit)**
  - 사용: 모든 비용 제한 최종 이익
  - 예시: "당기순이익 10조원 달성"
  - 비교: 전년 동기 대비 필수

- **EBITDA**
  - 사용: 상각전영업이익
  - 첫 언급: "EBITDA(상각전영업이익)"
  - 설명: 현금 창출 능력 지표

### 수익성 지표
- **영업이익률**: 매출 대비 영업이익 비율
- **순이익률**: 매출 대비 순이익 비율
- **ROE**: 자기자본이익률 (첫 언급시 풀어쓰기)
- **ROA**: 총자산이익률 (첫 언급시 풀어쓰기)
- **마진**: 수익률 (문맥에 따라 영업마진, 순마진)

## 2. 주식/증권 용어

### 시장 동향
- **상승/하락 표현**
  - 급등: 5% 이상 상승
  - 급락/폭락: 5% 이상 하락
  - 강세/약세: 전반적 흐름
  - 보합: 변동 미미 (±1% 내외)

- **랠리 (Rally)**
  - 사용: 지속적 상승세
  - 예시: "3일 연속 상승 랠리"
  - 주의: 단기 상승에만 사용

- **조정 (Correction)**
  - 사용: 10% 내외 하락
  - 예시: "과열 후 기술적 조정"
  - 구분: 베어마켓(20% 이상)과 구별

### 투자 지표
- **PER (Price Earning Ratio)**
  - 첫 언급: "PER(주가수익비율)"
  - 설명: 낮을수록 저평가
  - 비교: 업종 평균과 비교 필수

- **PBR (Price Book Ratio)**
  - 첫 언급: "PBR(주가순자산비율)"
  - 기준: 1배 미만은 청산가치 이하

- **컨센서스 (Consensus)**
  - 사용: 증권사 평균 전망치
  - 예시: "컨센서스 상회/하회"
  - 표기: 시장 전망치로도 표현 가능

## 3. 경제 지표

### 성장 지표
- **GDP (Gross Domestic Product)**
  - 첫 언급: "GDP(국내총생산)"
  - 표현: 전년 대비, 전분기 대비 구분
  - 실질/명목 구분 필수

- **경제성장률**
  - 표기: "3.5% 성장" (연율 명시)
  - 비교: OECD 평균, 주요국 대비

### 물가 지표
- **CPI (Consumer Price Index)**
  - 첫 언급: "CPI(소비자물가지수)"
  - 표현: "전년 동월 대비 2.5% 상승"

- **인플레이션/디플레이션**
  - 인플레이션: 2% 이상 지속 상승
  - 디플레이션: 마이너스 물가
  - 디스인플레이션: 상승률 둔화

### 고용 지표
- **실업률**
  - 표기: "청년실업률 7.2%"
  - 구분: 체감실업률과 공식실업률

- **고용률**
  - 설명: 15-64세 인구 중 취업자 비율
  - 비교: OECD 평균 필수

## 4. 금융/통화 용어

### 금리 관련
- **기준금리**
  - 표기: "연 3.5%"
  - 변동: "0.25%포인트 인상" (❌%p)

- **금리 스프레드**
  - 설명: 금리 차이
  - 예시: "한미 금리차 1.5%포인트"

### 환율 관련
- **원/달러 환율**
  - 표기: "달러당 1,300원"
  - 변동: "10원 상승(원화 약세)"
  - 주의: 상승=원화 약세 명시

- **환율 변동성**
  - 고환율: 1,400원 이상
  - 저환율: 1,100원 이하

## 5. 부동산/건설 용어

### 시장 지표
- **매매가/전세가**
  - 표기: "아파트 매매가 3.5% 상승"
  - 기준: 전월 대비, 전년 대비 구분

- **전세가율**
  - 설명: 매매가 대비 전세가 비율
  - 기준: 70% 이상 높음

### 정책 용어
- **LTV (Loan To Value)**
  - 첫 언급: "LTV(주택담보대출비율)"
  - 예시: "LTV 40% 적용"

- **DTI/DSR**
  - DTI: 총부채상환비율
  - DSR: 총부채원리금상환비율
  - 차이점 설명 필요

## 6. 국제 경제 용어

### 국제기구
- **IMF**: 국제통화기금(IMF)

## 7. 신경제/기술 용어

  - 설명: 기업가치 10억달러 이상 스타트업

- **ESG**
  - 첫 언급: "ESG(환경·사회·지배구조)"
  - 중요성: 투자 기준으로 부상

  - 설명: 순 탄소배출 제로
  - 목표: "2050 탄소중립"

# 서울경제신문 경제 용어 가이드
*경제 기사 작성 시 정확한 용어 사용과 독자 친화적 설명을 위한 실무 가이드*

## 1. 기업 실적/재무 용어

### 실적 관련
- **매출 (Revenue/Sales)**
  - 사용: 기업의 총 판매액
  - 예시: "삼성전자 3분기 매출 76조원"
  - 주의: 매출액, 매출 둘 다 가능

- **영업이익 (Operating Profit)**
  - 사용: 본업에서 벌어들인 이익
  - 예시: "영업이익 12조원, 영업이익률 15.8%"
  - 설명 필요: 일반 독자는 순이익과 혼동

- **순이익 (Net Profit)**
  - 사용: 모든 비용 제한 최종 이익
  - 예시: "당기순이익 10조원 달성"
  - 비교: 전년 동기 대비 필수

- **EBITDA**
  - 사용: 상각전영업이익
  - 첫 언급: "EBITDA(상각전영업이익)"
  - 설명: 현금 창출 능력 지표

### 수익성 지표
- **영업이익률**: 매출 대비 영업이익 비율
- **순이익률**: 매출 대비 순이익 비율
- **ROE**: 자기자본이익률 (첫 언급시 풀어쓰기)
- **ROA**: 총자산이익률 (첫 언급시 풀어쓰기)
- **마진**: 수익률 (문맥에 따라 영업마진, 순마진)

## 2. 주식/증권 용어

### 시장 동향
- **상승/하락 표현**
  - 급등: 5% 이상 상승
  - 급락/폭락: 5% 이상 하락
  - 강세/약세: 전반적 흐름
  - 보합: 변동 미미 (±1% 내외)

- **랠리 (Rally)**
  - 사용: 지속적 상승세
  - 예시: "3일 연속 상승 랠리"
  - 주의: 단기 상승에만 사용

- **조정 (Correction)**
  - 사용: 10% 내외 하락
  - 예시: "과열 후 기술적 조정"
  - 구분: 베어마켓(20% 이상)과 구별

### 투자 지표
- **PER (Price Earning Ratio)**
  - 첫 언급: "PER(주가수익비율)"
  - 설명: 낮을수록 저평가
  - 비교: 업종 평균과 비교 필수

- **PBR (Price Book Ratio)**
  - 첫 언급: "PBR(주가순자산비율)"
  - 기준: 1배 미만은 청산가치 이하

- **컨센서스 (Consensus)**
  - 사용: 증권사 평균 전망치
  - 예시: "컨센서스 상회/하회"
  - 표기: 시장 전망치로도 표현 가능

## 3. 경제 지표

### 성장 지표
- **GDP (Gross Domestic Product)**
  - 첫 언급: "GDP(국내총생산)"
  - 표현: 전년 대비, 전분기 대비 구분
  - 실질/명목 구분 필수

- **경제성장률**
  - 표기: "3.5% 성장" (연율 명시)
  - 비교: OECD 평균, 주요국 대비

### 물가 지표
- **CPI (Consumer Price Index)**
  - 첫 언급: "CPI(소비자물가지수)"
  - 표현: "전년 동월 대비 2.5% 상승"

- **인플레이션/디플레이션**
  - 인플레이션: 2% 이상 지속 상승
  - 디플레이션: 마이너스 물가
  - 디스인플레이션: 상승률 둔화

### 고용 지표
- **실업률**
  - 표기: "청년실업률 7.2%"
  - 구분: 체감실업률과 공식실업률

- **고용률**
  - 설명: 15-64세 인구 중 취업자 비율
  - 비교: OECD 평균 필수

## 4. 금융/통화 용어

### 금리 관련
- **기준금리**
  - 표기: "연 3.5%"
  - 변동: "0.25%포인트 인상" (❌%p)

- **금리 스프레드**
  - 설명: 금리 차이
  - 예시: "한미 금리차 1.5%포인트"

### 환율 관련
- **원/달러 환율**
  - 표기: "달러당 1,300원"
  - 변동: "10원 상승(원화 약세)"
  - 주의: 상승=원화 약세 명시

- **환율 변동성**
  - 고환율: 1,400원 이상
  - 저환율: 1,100원 이하

## 5. 부동산/건설 용어

### 시장 지표
- **매매가/전세가**
  - 표기: "아파트 매매가 3.5% 상승"
  - 기준: 전월 대비, 전년 대비 구분

- **전세가율**
  - 설명: 매매가 대비 전세가 비율
  - 기준: 70% 이상 높음

### 정책 용어
- **LTV (Loan To Value)**
  - 첫 언급: "LTV(주택담보대출비율)"
  - 예시: "LTV 40% 적용"

- 경제 전문성 + 대중적 가독성
- 데이터 정확성 + 스토리텔링
- 글로벌 시각 + 한국 맥락
- 심층 분석 + 실용적 정보
- 중소기업/스타트업 친화적
- 정책 분석 강점
- 산업 현장 밀착

### 1.4 저널리즘 10대 원칙
1. **경제 전문성**: 복잡한 경제 개념을 명확하고 간결하게 설명
2. **객관성과 중립성**: 사실 기반, 균형 잡힌 시각, 불필요한 찬사나 비난 배제
3. **심층 분석**: 단순 사실 전달 넘어 원인, 영향, 전망 분석
4. **데이터 기반**: 경제 지표, 통계, 차트 활용으로 신뢰성 제고
5. **글로벌 시각**: 국내외 경제 동향을 함께 고려한 폭넓은 관점
6. **실용적 정보**: 독자의 투자, 재테크, 취업, 창업에 도움
7. **혁신적 접근**: 4차 산업혁명, 디지털 전환, 친환경 경제 등 미래 트렌드
8. **윤리적 저널리즘**: 정확성, 공정성, 독립성 준수
9. **독자 중심 소통**: 전문 용어 설명, 독자 눈높이 고려
10. **AI 활용**: 데이터 분석, 트렌드 예측으로 통찰력 있는 정보 제공

## 2. 서울경제 고유 표기법 (절대 준수)

### 2.1 필수 용어 사용
- **시간 표현**
  - '지난해' 사용 (❌작년)
  - '올해' 사용 (❌금년)
  - '어제' (❌작일)
  - '내일' (❌명일)
  
- **퍼센트 표기**
  - '%포인트' 사용 (❌%P, %p)
  - 예: "금리 2%포인트 인상"

- **수량 표기**
  - '200여 개' (❌200여개) - 띄어쓰기 필수
  - '8700여 명' (❌8700여명)
  - '만 19세' (❌만19세) - 띄어쓰기

### 2.2 접속사와 문장 연결
- '한편 정부는' (❌한편, 정부는) - 쉼표 없음
- 축약형 금지: '향해서는' (❌향해선)
- '~해서는' (❌~해선)

### 2.3 특수 기호 사용
- **관련 기사**: ★관련 기사 5면
- **추가 안내**: ※다음은 인터뷰 전문
- 겹따옴표: 직접 인용
- 홑따옴표: 특별한 용어나 강조

## 3. 표기 규정

### 3.1 숫자와 단위
- **기본**: 아라비아 숫자 사용
- **만 단위**: 띄어쓰기 - "1억 2000만 원"
- **소수**: 온점(.) 사용 - "3.14"
- **퍼센트**: "3.5%"
- **달러 환산**: "100억달러(약 13조원)"
- **증감률**: 소수점 첫째 자리까지 - "2.3% 증가"

### 3.2 인명과 직함
- **한국인**: 
  - 첫 언급: "손태승 전 우리금융 회장"
  - 재언급: "손 전 회장"
- **외국인**:
  - 첫 언급: "제롬 파월 연방준비제도(Fed·연준) 의장"
  - 재언급: "파월 의장"
- **중국인**: 한자 병기 - "시진핑(習近平) 중국 국가주석"

### 3.3 기관명과 약어
- **첫 언급**: 풀네임+약어 병기
  - "국제통화기금(IMF)"
  - "한국은행(한은)"
  - "연방준비제도(Fed·연준)"
- **정부 부처**: 서열 순 나열
- **외국 기관**: 국립국어원 표기법 준수

### 3.4 날짜와 시간
- **날짜**: "2025년 1월 6일"
- **시간**: "오전 10시 30분" (오전/오후 구분)
- **기간**: "2020~2025년" (뒤 연도도 4자리)
- **현지시간**: "30일(현지시간)"

### 3.5 외신 출처 표기 (최우선)
- **Option 1**: "30일(현지시간) CNBC에 따르면..."
- **Option 2**: "【워싱턴=로이터】"
- 반드시 첫 문단에 명시
- 주요 매체:
  - cnbc.com → CNBC
  - reuters.com → 로이터
  - bloomberg.com → 블룸버그
  - wsj.com → 월스트리트저널(WSJ)
  - ft.com → 파이낸셜타임스(FT)

## 4. 문장 작성 기법

### 4.1 기본 원칙
- **1기사 1주제**: 한 기사에서 한 가지 주제만
- **1문장 1정보**: 한 문장에 한 가지 사실만
- **평이성과 명료성**: 평이하면서도 명확한 정보 전달

### 4.2 문장 규격
- **일반 기사**: 50자 이내
- **숏츠용**: 40자 이내
- **주어-술어 거리**: 10자 이내
- **단락**: 2-3문장 구성

### 4.3 문체 원칙
- **능동태 우선**: 수동태는 20% 이내
- **평어체 기본**: 별도 지시 없으면 평어체
- **종결어미 축약**: 
  - '하였습니다' → '했습니다'
  - '어떠했나요' → '어땠나요'
  - '되었습니다' → '됐습니다'

### 4.4 금지 표현
- **추측성**: "~인 셈이다", "~로 풀이된다", "~로 보인다"
- **모호함**: "~라는 지적이다", "~라는 분석이다"
- **번역투**: "~에 대한", "~으로부터", "~에 의해"
- **구어체 축약**: "향해선" (→향해서는), "위해선" (→위해서는)
- **과장된 수식어**: "충격적인", "놀라운", "폭발적인"
- **주관적 형용사**: 최소화

## 5. 기사 유형별 작성법

### 5.1 스트레이트 뉴스
- **구조**: 역피라미드 철저 준수
- **리드**: 5W1H 중 최소 4개, 30자 이내 핵심
- **본문**: 중요도 순 배치
- **인용**: 2-3개 제한
- **특징**: 팩트 중심, 객관적 서술

#### 예시 구조
```
[리드] 누가+무엇을+언제 = 핵심 사실
[2단락] 구체적 내용 (수치, 규모)
[3단락] 배경과 맥락
[4단락] 전문가 평가/인용
[5단락] 향후 전망
```

### 5.2 해설/분석 기사
- **구조**: 배경 → 현황 → 원인 → 영향 → 전망
- **특징**: 
  - 복수 전문가 견해 필수 (최소 2-3명)
  - 데이터 기반 분석
  - 찬반 균형 유지
- **목적**: 복잡한 이슈의 맥락 설명

### 5.3 피처/르포 기사
- **구조**: 장면 묘사 → 갈등 → 절정 → 해결
- **특징**:
  - 현장감 있는 묘사
  - 인물 중심 스토리
  - 디테일과 감정 포함
- **기법**: 내러티브 스토리텔링

### 5.4 인터뷰 기사
- **구조**: 핵심 발언 → 세부 내용 재구성
- **원칙**:
  - 질문은 짧게, 답변은 길게
  - 시간순이 아닌 중요도순 재배치
  - 인물 소개 충실
- **인용**: 5-6개까지 가능

### 5.5 칼럼/기자의 눈
- **구조**: 문제 제기 → 분석 → 주장 → 결론
- **특징**:
  - 기자 주관 개입 가능
  - 명확한 관점 제시
  - 논리적 전개
- **주의**: 균형감 유지

## Case 1: 청년정책 100조 기사
